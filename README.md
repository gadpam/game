# «ПОКА ПОВРЕМЕНИМ» · Том 1 (главы 1–5)

Вертикальный вебтун (16+) о пятнадцатилетнем центральном полузащитнике **Ветрове** из клуба **«Торпедо-2»** (Вторая лига Беларуси, Витебск) и текстовой **Системе**, которая считает в его игре то, чего не видит протокол матча.

- **Тон:** сухой, наблюдательный, живая футбольная речь без пафоса и книжных присказок.
- **Визуальные и повествовательные ориентиры:** *Solo Leveling* (REDICE Studio) и *«Я притворился футбольным гением»*.
- **Правило утверждения:** автор — единственная утверждающая инстанция; в канон ничего не входит без явного слова **«утверждаю»**. Работа идёт строго по одной главе за раз. Глава 6 не начинается до отдельного разрешения автора.

## Регламент документирования («правило 5 шагов»)

1. Каждый завершённый содержательный шаг работы (перерисовка/правка кадра, редактура текста, пересборка ленты, читательский аудит главы, утверждение главы) учитывается в счётчике в `docs/WORKFLOW_LOG.md` (`1/5 … 5/5`).
2. Каждая конкретная правка кадра или текста сразу фиксируется в `docs/QC_CH1-5_2026-11-13.md` по формуле **«глава N · кадр NN · было → стало · почему»**.
3. **Строго каждые 5 шагов** выполняется контрольная точка (**CHECKPOINT**):
   - обновляются `docs/WORKFLOW_LOG.md` (пройденные 5 шагов, открытые замечания, сброс счётчика на `0/5`), `docs/CHAPTERS.md` (раскадровка/файлы, если менялись) и `README.md` (таблица статуса и метрик);
   - проверяется чистота рабочего дерева (временные файлы и дубликаты остаются в `_backup/`, исключённом через `.gitignore`);
   - изменения фиксируются коммитом и отправляются (`git push`) в активную ветку репозитория на GitHub.
4. Внеплановая фиксация в Git также делается при утверждении целой главы («утверждаю») или по прямому запросу автора.

## Сборка конвейера

Зависимости (Python 3.11+):

```bash
pip install pillow fonttools numpy
```

Полная пересборка всех артефактов из исходников (оригиналы `.jpg` в `ch1/`–`ch5/` при леттеринге не перезаписываются):

```bash
python3 build_insets.py       # 1. Кириллица на листах заявок и в тетрадях (из *_src.jpg)
python3 build_h27.py          # 2. Кадр блокнота h27_notebook.jpg (гл. 4)
python3 build_panels_all.py   # 3. 13 окон Системы + проверка канона чисел, глифов и геометрии
python3 build_lettering.py    # 4. Леттеринг и проверка 0 пересечений баблов
python3 build_scrolls.py      # 5. Склейка CH1..CH5_SCROLL_SL_full.jpg и CH1..CH5_SL_SHEET.jpg
```

## Неприкосновенные правила канона и авторские решения

- **Мир:** реален только Витебск; все клубы вымышлены («Торпедо-2», «Речник» и др.); Вторая лига Беларуси.
- **Герой (Ветров, 15 лет, ЦПЗ, №19 по канону):** светло-чёрные (мягкий угольно-чёрный) волосы, спокойные серые глаза (эталон лица — `ch1/f08_eyes.jpg`); не плачет и не кричит; мать — не более 2 реплик за том.
- **Форма «Торпедо-2»:** строго чёрно-белая — белая футболка с тонким чёрным воротом и манжетами, чёрные шорты, чёрные гетры, чёрные бутсы без брендов. **На форме никаких номеров и логотипов.**
- **Футбольный реализм:** заявка на матч — 18 человек (11 старт + 7 запас); в гл. 1 Ветров выходит на `72′` при счёте `2:0` из-за дискомфорта задней поверхности бедра у стартового ЦПЗ Шатского.
- **Система:** только текст в голографическом окне в стиле *Solo Leveling* (шрифт Exo 2), без голоса, без `LEVEL UP`, XP и прогресс-баров, не более 2 панелей на сцену. В гл. 1 появляется впервые в жизни строго на `72′` при выходе на поле на пике волнения.
- **Математика:** 12 характеристик (0–70), `ОБЩ` = среднее 12 (`444 / 37.00` старт → `443 / 36.92` гл. 1–4 после `ОТБОР 26→25` → `444 / 37.00` гл. 5 после `ВЫНОСЛИВОСТЬ 38→39`); `ИВ = 68` в томе 1; кредиты квестов `+N` в кадре не печатаются никогда; ставка — всегда одна из 12 характеристик; провал = `−1`; прирост `+1` не более 3 атрибутов в месяц; старые 6 метрик и слово «ЯКОРЬ» запрещены.
- **Типографика панелей:** стрелки и ромбы рисуются геометрией в `grid.py` (символы `→ ◆ ▲ ▸ ＋` в шрифте не используются).
